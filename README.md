## 怎么确认是新版

封面左上角：

```
┌─────────────────┐
│  ⬤ 国家教材委员会  │
│    审核通过 2024   │
└─────────────────┘
```

- ✅ 有这枚徽标 = 2024 审定新版
- ❌ 没有 = 2018 审定旧版（旧版封面是纯色底 + 白色圆形里的书名，很好认）

新版封面还有一个特征：书名是**对话气泡**样式，背景是整幅场景插画（语文是山水、数学是滑雪大跳台、英语是城市天际线、道法是少年与白鸽）。
